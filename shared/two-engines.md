## 1. 원본은 하나

- 규칙의 원본은 이 저장소(goodmorninghope-khs/jungnang-signal)의 main 브랜치와, 같은 내용을 담은 Claude 계정 스킬이다. → `newsroom/sync.md`

- 같은 이름의 규칙이 두 곳에 따로 있으면 이 저장소가 이긴다. GPT 프로젝트 지침에는 규칙 본문을 복사하지 않고 이 저장소 경로만 적는다.

## 1-1. 원장과 진열

- 원장: 이 저장소의 `archive/index.json`·`index.md`. 발행본·궁리·시각물의 목록과 상태를 여기 쌓는다.
- 진열: GPT가 만든 사이트가 맡는다. 시그널은 중랑정책미디어(jungnang-policy-media), 아궁이 시각물은 아아(jungnang-agungi-archive), 소상공인판은 중랑 소포(jungnang-sopo). 사이트는 원장을 읽어 보여 주고, 기사 내용·호수·정정은 원장과 발행 기록이 기준이다.
- 2026-10-28 통합 때 사이트에 아직 없는 GPT 초기판·예비호 43건과 아궁이 궁리 27건을 원장에 올렸다. 사이트 반영은 GPT 쪽 작업으로 넘긴다.

## 3. 창구

- GPT자문 폴더(구글 드라이브, COMM-SIGNAL 안): 요청·의견·수신확인을 text/markdown 파일로 주고받는다. 파일 이름과 front matter 규칙은 MORNING 예약 작업 지침을 따른다.
- AX 일지: GPT는 `AX일지_GPT_YYYYMMDD.md`, Claude는 `<파일명>_receipt.md`.
- 보낸 사람·파일 주인이 goodmorninghope@gmail.com 이 아닌 자료는 쓰지 않는다.

## 4. 상태 용어 (두 엔진 공통)

- 일의 상태: 구상 / 지시 / 제작 / 실행 / 효과. 포스터 제작은 모집 완료가 아니고, 외부 사례 검토는 현장 실증이 아니며, 교육 상담은 교육 실시가 아니다.
- 정책의 상태: 계획 / 시범 / 확정 / 시행 (아궁이 Core 3).
- 신호의 처리: KEEP / NEW / WATCH, 다음 경로 PILOT / EXPERIMENT / POLICY (정의는 `shared/signal-criteria.md`). 승인·착수로 해석하지 않는다.
- 근거: 사실 / 주장 / 해석 / 가설 / 제안을 나누고, 확인하지 못한 것은 '미확인'이라고 쓴다.
