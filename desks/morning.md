## 4. 신호 고르기

- **머리는 밖에서.** 국내외 연구보고서, 정부 원문, 다른 도시와 해외의 실행 사례에서 고른다. 중랑 현안을 머리로 올리지 않는다.
- **신호 2~3개.** 좋은 것이 둘이면 둘만 쓴다. 해외 1~2, 국내(정부 원문·국책·지역 연구·다른 지자체 실행) 1~2로 맞추고, 한 주 단위로 한쪽이 60%를 넘지 않게 한다.
- **근거 위계.** 연구보고서·공식 통계·정부 원문 > 해외 도시·기관 실행 사례 > 언론(교차 확인). 매주 해외 연구 1편 이상.
- **닿는 공약.** 민선9기 7대 비전 또는 구정 주요 사항(중랑 AX2030 등)에 닿는 촉을 고른다. 한 호에 서로 다른 비전 2~3개를 권한다. 기준은 `shared/pledge-map.md`.
- **고르는 기준.** 새로움·시의성, 중랑의 의사결정에 주는 도움, 기존 정책을 보완하거나 재구조화할 가치, 중앙정부·서울시보다 먼저 준비할 수 있는가, 주민 체감, 최근 신호와 겹치는가. 판별은 `shared/signal-criteria.md`를 따른다.
- 세 신호는 서로 다른 소재로, 최소 두 개 주제 영역에 걸친다. 같은 영역이 사흘 연속 머리가 되지 않게 한다.
- 반복 소재(행안부 AX·AI 챔피언·AI 정부 실험실 등)는 새 전환점이 없으면 다시 고르지 않는다.
- GPT 촉 후보를 후보 풀에 먼저 넣고, 원문을 직접 열어 확인한 것만 쓴다. 쓰지 못한 후보는 이유(열림 실패 / 결과 전 / 공약 연결 약함)를 기록한다(상시 실험 '출처 도착').
- 새 정책 발굴보다 지난 8년의 축적과 민선9기 공약의 재정렬·재구조화를 먼저 본다. 외부 신호가 기존 공약의 직접 이행·이행방식 개선·보완에 보탬이 되면 신규 사업보다 앞에 둔다. 중랑의 해법이 서울과 대한민국의 보편 문제를 푸는 JUNGNANG STANDARD로 자랄 가능성도 함께 본다.
- PEOPLE 신호는 좋은 인물이 있을 때만 고른다.

## 5. 신호 쓰기

순서는 촉 → 읽기 → 침이다. 단, E4(11/5) 하루는 실험표가 앞선다(Q → 촉 → 읽기 → 침).

| 칸 | 분량 | 무엇을 |
|---|---|---|
| 촉 | 2줄 안팎 | 무엇이 바뀌었나. 자료명·발표일·원문 링크 |
| 읽기 | 2줄 안팎 | 왜 의미 있나. 다른 곳이 어떻게 풀었는지(방법), 무엇이 나아졌는지(증거), 어떤 한계가 있었는지(한계) |
| 옮겨 볼 조건 | 1줄 (11/3부터) | 성과 옆에 비용·대상·운영 조건 가운데 핵심 하나 |
| 침 · 중랑에 적용한다면 | 1줄 | 중랑이 이미 하는 일에서 출발하는 작은 실험 하나. '편집국 의견' 표시 |
| 닿는 공약 | 꼬리표 | 비전 이름을 말로 쓴다(예: 비전·복지). 사업명은 원문으로 확인될 때만 쓰고 사업번호는 만들지 않는다. 연계 유형(직접 이행 / 이행방식 개선 / 보완 제안 / 신규 검토)은 텍스트판에 적는다 |

- 중랑은 침 단락에서만 이름으로 등장한다. 중랑의 기존 실천은 원문으로 확인된 것만 쓴다. 처음 쓴 실천은 알림에 적어 reference-hub의 '중랑이 이미 하고 있는 일' 표에 쌓이게 한다.
- 사실·해석·제안을 나눈다. 계획·검토·시범·확정·시행도 나눈다. 자료상 계획을 확정이나 완료로 쓰지 않는다. 제안이나 도해 제작을 실행으로 쓰지 않는다.

- 1차 자료를 먼저 보고, 중요한 사실은 교차 확인한다. 원문에 닿지 못한 것은 '미확인'에 적는다.
- 이전 자료를 다시 읽은 것과 새 소식을 구분한다. 한 주제 안에서만 세 신호를 고르면 '주제 특집'으로 표시한다.
- 문장은 한 문장에 한 정보, 결론 먼저, 능동형으로 쓴다. 같은 개념은 같은 말로 쓰고, 어려운 말은 바로 풀이한다(ASD-STE100 취지).

## 6. 문체 — 읽는 공무원이 평가받는다고 느끼지 않게

- **잘한 데서 출발해 더 잘하자.** 중랑이 이미 하는 일과 쌓은 자산을 먼저 적고, 밖의 사례로 "여기에 한 걸음 더하면"을 건넨다.
- 문제를 고발하거나 채점하지 않는다. 없는 것, 늦은 것, 빠진 것을 세지 않는다.
- 중랑구 부서를 거론하거나 평가하지 않는다.
- 제목: 중랑 지명이 들어간 머리 제목, '없다·않았다·아직·담당이 없다·이어지지 않는다' 같은 미비 지적형 제목을 쓰지 않는다. MORNING 주기사 제목은 사실형이 기본이다.
- 어미: "~해야 한다·~하라·~할 것" 대신 "~해 보면 어떨까요·~를 검토해 볼 만합니다·~부터 함께 시작해 볼 수 있습니다"로 쓴다.
- 판단과 결정은 각 부서와 발행인의 몫이다. 침은 편집국 의견이며 행정 결정이 아니다.

| 이렇게 쓰지 않고 | 이렇게 |
|---|---|
| 중랑은 아직 ○○이 없다 | 중랑의 △△에 ○○을 더해 볼 수 있습니다 |
| ○○과가 챙겨야 한다 | (부서 이름 없이) ○○부터 함께 시작해 볼 수 있습니다 |
| 지난 제안은 진행되지 않았다 | (쓰지 않는다. 확인된 새 소식이 있을 때만 '후속'으로) |

## 7. 마감

**지면 끝에 두는 것**
- **JUNGNANG Q** 하나. 답을 정해 두지 않은 열린 물음이다. 추궁이나 숙제로 읽히지 않게 쓴다(그동안 BIG Q로 불러 온 자리).
- **권하는 것 / 피하면 좋은 것** 각 한 문장. 오늘 신호를 관통하는 행정의 실행 원칙이다. 사람·정당·정책의 우열평가나 정치적 찬반이 아니다. 근거가 부족하면 쓰지 않고 Q로 남긴다.
- **두 시선.** 두 엔진의 읽기가 갈릴 때만 "Claude는… / GPT는…" 한두 줄로 남긴다(`shared/convergence.md`). E2(11/3)에는 침 씨앗을 쓰지 않은 이유를 여기에 적는다.

**텍스트판에 두는 것** (11/9부터 1면에서 뺀다. 11/6까지는 지금처럼 1면 하단에 두어도 된다)
- **SIGNAL PROMPT** 하나. 자기 업무에 대입해 볼 입력문이다. Q와 같은 문장을 되풀이하지 않는다.
- **ROUTE.** KEEP / NEW / WATCH와 다음 자리(아궁이 / ISSUE / EXPERIMENT / POLICY / ARCHIVE)를 적는다. 아궁이에 올릴 궁리도 여기에 함께 적는다.
- **정정·보탬·후속, 미확인.** 형식은 `shared/textpan-spec.md`를 따른다.

**지난 침의 소식**

- 지난 침을 점검표로 세지 않는다. 확인된 새 소식이 있을 때만 텍스트판 '후속'에 한 줄로 적는다.
- 침의 행방(건넴 → 함께 봄 → 시범 → 이어 감 / 쉬어 감)은 부서가 알려 주었거나 공식 원문으로 확인된 때만 단계를 바꾼다. 틀은 11/9에 만들고 창간호부터 운영한다.
- 한 주의 소식은 WEEKLY '지난 침, 이어 온 소식'이 모은다.

## 8. 지면(IMAGE)

- **TEXT → IMAGE 순서.** TEXT를 완성·검증한 뒤 같은 순서·수치·날짜·표현으로 IMAGE를 만든다. IMAGE에 TEXT에 없는 사실을 더하지 않는다. 둘 중 하나가 빠지면 완성 발행이 아니며, 빠진 것을 알림에 적는다. 완성본은 TEXT와 IMAGE를 같은 실행에서 함께 낸다.
- 판형과 치수는 `shared/tabloid-design.md`(2026-10-30 개정 포함)를 따르고, `shared/tabloid-template.html`에서 출발한다.
- **기준판 0917.png의 문법.** 크게 보이는 개별 제호, 가장 큰 주기사 하나와 대표 사진 또는 도해, 확실히 작은 보조기사 1~2개(각자 제목과 근거), 정렬된 단과 얇은 구획선. 세 신호를 같은 크기 3단으로 두지 않는다. 카드뉴스·대시보드·같은 크기 상자 나열을 피한다. 거대한 공통 삽화를 모든 신호 위에 두지 않는다. 기준판의 기사 사실·수치·옛 캐릭터는 옮겨 쓰지 않는다.
- 바탕은 연회색 신문 용지, 활자는 네이비·검정·회색, 포인트 컬러는 기능적으로 하나만 쓴다.
- 사진은 실제 사진이거나 '개념도·개념 이미지'로 표시한 것만 쓴다.
- **두부.** 흰 두부 한 모, 둥근 모서리, 상단의 작은 초록 잎, 따뜻한 표정과 볼 홍조가 기본형이다. 문장부호처럼 Q 곁에 작게 두고, 주기사·사진·도해보다 커지지 않게 한다. 표정·포즈·소품만 바꾼다. 시냥·Q냥은 쓰지 않는다.
- 이미지는 3초·30초 층(제목·도해·촉·침·Q)을 맡고, 본문은 텍스트판이 맡는다. 1200px 원본을 함께 전달한다.
- 다른 지면도 이 편집 문법을 나눠 쓰되, 제호·분량·판형·코너는 각 지면 파일을 따른다.

## 9. 다른 지면과의 역할

| 지면 | 역할 |
|---|---|
| MORNING | 새 신호 발견과 그날의 '권하는 것' 후보 |
| WEEKLY | 주간 연결과 숙성, 국장회의 의제('이번 주 침') |
| WEEKLY AX | AX 구조와 실행 심화 |
| ISSUE | 한 쟁점 심층 |
| 두부 | 리더십 사례와 패턴 |
| SOPO | 소상공인의 행동·도구·조건으로 번역 |

같은 신호를 그대로 옮기지 않는다. 다시 실을 때는 새 근거·연결·반론·실행 조건·결정 가치 가운데 하나 이상을 더한다. 한 신호가 ISSUE로 이어지면 MORNING은 발견과 짧은 질문을, ISSUE는 새 근거·반론·조건을 맡는다.
