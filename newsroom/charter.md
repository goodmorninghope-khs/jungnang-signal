## 한 편집국, 여러 지면

JUNGNANG SIGNAL의 모든 지면은 한 편집국이 만든다. 촉은 한 번 모으고, 신호는 지면마다 다르게 쓴다.
한 사람이 찾고, 고르고, 쓰고, 검증하면 자기가 고른 신호를 자기가 믿게 된다. 편집국은 이 일을 나누어 각 역할이 앞 역할의 결과를 다시 묻게 한다.
"밖에서의 촉을, 중랑을 건강하게 하는 침으로"를 분업으로 구현한다.

## 내각에서의 자리

편집국은 김현성 내각의 국정소통부이고, 편집국장이 국정소통장관이다. 내각과는 우편함 두 통로(발행 보고, 승인된 카드 접수)로만 닿는다. 편집권은 그대로 편집국에 있다. → newsroom/cabinet.md

## 신호의 흐름

MORNING 발견 → (ISSUE 심층, 컨펌 시) → WEEKLY·AX 숙성 → 아궁이 설계·작은 실험 → 현장 확인 → 다시 SIGNAL.
같은 소재가 다른 지면에 다시 나올 때는 새 근거·연결·반론·실행조건·결정가치 중 하나 이상을 더한다. 국장은 편성 때 이 규칙을 지킨다.

## 고문의 두 시점

- 촉 단계 사전 의견: 내부 고문이 그날 카드에, GPT가 전날 밤 다음 호 우선 영역과 후보로 의견을 낸다.
- 침 단계 사후 의견: 침과 지면은 고문 확인 없이 발행하고, 고문단이 발행 뒤에 검토한다. 다음 호 전호 점검에 반영된다.
- 사실 오류 지적은 예외 없이 고치거나 해당 카드·문장을 뺀다.

## 회의록 서식

제목: 편집회의 YYYY-MM-DD · (지면) 제N호

1. 전호 점검: 전호 Do/ACTION 상태, 고문 사후 의견과 오늘 반영한 것
2. GPT 의견: 도착 여부, 우선 영역, 후보의 채택·탈락과 이유
3. 촉: 받은 카드 수, 갈래별 수 (주간 지면은 신호 창고에서 가져온 카드)
4. 내부 고문 사전 의견과 수용 여부
5. 선정과 침
6. 결정: 주기사·보조기사, Do/不, BIG Q, ROUTE
7. 침·지면 사후 의견(내부 고문)
8. ISSUE·PEOPLE 후보와 컨펌 상태
9. 남은 질문: WATCH와 다음 확인
