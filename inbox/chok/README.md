# inbox/chok · GPT 촉 레이더 후보함

- 매일 저녁 GPT(촉 레이더)가 다음 날 MORNING용 촉 후보 3~5개를 ChatGPT 「09 중랑시그널·소포 편집실」 프로젝트 대화에 올리면, Aside 통합 데스크가 이 폴더에 CHOK-YYYYMMDD.md(발행일 기준)로 옮긴다.
- Claude 편집국은 MORNING 실행 첫머리에 오늘 날짜 파일을 읽고, 원문을 직접 확인한 후보만 쓴다. 채택·제외는 회의록 §2와 알림에 남긴다.

## 후보별 ‘옮겨 볼 조건’ · 발행인 요청 2026-10-30

- 2026-11-02(월) 발행분용 후보부터 모든 촉 후보에 `옮겨 볼 조건:` 한 줄을 붙인다. 후보 작성일이 아니라 대상 발행일 기준이다.
- 외부 사례의 비용·대상·운영 조건 중 중랑에 옮길 때 핵심이 되는 조건을 원문 근거로 적는다. 편집 해석이 섞이면 사실과 제안을 구분한다.
- 비용이나 조건이 공개되지 않았거나 원문에서 확인되지 않으면 `비용 미공개`·`대상 범위 확인 필요`처럼 적고 숫자를 추정하지 않는다. 자료를 열지 못하면 `열지 못함`이라고 적는다.
- 형식: `옮겨 볼 조건: [확인된 핵심 조건]. 중랑 적용 시 [검토할 조건·제안].`
- 이 기준 추가는 기존 Aside 전달 경로를 유지하며 새 예약이나 자동발행을 만들지 않는다.
