# 아궁이 편집 가이드 v0.1

2026-10-02. 기존 이미지 세 장을 직접 확인해 추출한 편집 원칙과 개선 제안이다.
원본 이미지의 사실·인용·일정·수치·협력관계까지 승인하거나 재사용하지 않는다.

## 편집 목적

질문이 어떤 연결과 판단을 거쳐 작은 실험으로 이어지는지 한눈에 보이게 한다.
SIGNAL은 기사 중요도의 위계로, 아궁이는 생각과 정책의 관계로 편집한다.
초광폭은 내용을 빼곡히 넣으라는 뜻이 아니다. 관점은 넓게 살피고 시선은 한 방향으로 이끈다.

사용자가 학습 로드맵의 색감·구성, 공공 AI 로드맵의 톤앤매너를 긍정 평가한 대화를 함께 참고했다.
아래 비율·색상 수·배치 선택은 이 관찰을 반복 제작에 쓰기 위한 운영 제안이며 과거의 고정 규격이라고 단정하지 않는다.

## 먼저 한 문장을 정하기

제작 전에 네 가지를 텍스트로 확정한다: 핵심 질문 하나 / 새로운 연결의 원리 / 바꿀 주민 경험 / 첫 실험 또는 다음 확인.
기존 정책과 새 제안의 관계를 정리한 뒤 지면을 잡는다. 각 상자에 넣을 내용부터 채우지 않는다.
주민의 생활 장면을 도입이나 중심 시각물에 배치한다. 정책명을 모르더라도 문제를 이해할 수 있게 한다.

## 판형과 읽는 순서

- 초광폭 요청: 가로 2:1~3:1을 출발점으로 삼되 콘텐츠와 도구에 맞춘다. 이는 권장값이다.
- 일반 한 장: 16:9 또는 A4 가로 등 전달 환경에 맞춘다. 모바일은 확대 시 본문을 읽을 수 있게 원본을 제공한다.
- 축소 화면에서는 질문·주요 관계·결론이 먼저 읽혀야 한다. 원본에서도 본문이 읽히지 않으면 글씨를 키우고 항목을 줄인다.
- 상단: 작은 ‘아궁이 | 중랑정책주방’ 표기, 가장 큰 한국어 질문, 한 줄의 부제와 ‘새로운 연결, 다른 경험’.
- 본문: 문제와 근거→기존 자산의 새로운 연결→주민 경험과 작은 실험. 주요 구획은 3개 안팎을 기본으로 선택한다.
- 하단: 다음 행동·검증·학습 환류. 일정이 핵심일 때만 시간축을 둔다. 구체적 일정이 없으면 만들어 넣지 않는다.
- 구 슬로건 ‘나의 자랑, 우리 중랑’, 정책 모토 ‘새로운 연결, 다른 경험’, 철학 ‘뜻과 땀으로 때를 짓는다’의 역할을 구분한다. 모두 크게 반복하지 않는다.

## 내용에 맞는 지도 선택

| 과제 | 주된 시각 구조 | 반드시 남길 것 |
|---|---|---|
| 관점 전환·원인 탐색 | 좌→우 문제·재정의·대안 | 핵심 질문과 반례 |
| 자산·부서·민관 연결 | 중심 경험과 역할 연결 | 누가 무엇을 연결하는지 |
| 이용 여정·지역순환 | 단계 흐름 또는 하나의 순환 | 막히는 곳과 돌아오는 배움 |
| 실행 로드맵 | 단계별 시간축 | 제안/확정 상태와 확인 시점 |
| 데이터·권한·서비스 구조 | 층위도 | 주민 접점·책임·실행조건 |

한 장의 주된 구조는 하나로 선택한다. 시간축·층위도·순환·거대 마인드맵을 모두 겹치지 않는다.
화살표는 이동·인과·정보·협력 중 뜻을 정하고 필요하면 짧은 라벨을 붙인다. 관계가 확인되지 않으면 점선과 ‘가설’로 표시한다.
장식용 연결선과 서로 교차하는 화살표를 줄인다. 박스 크기는 중요도와 정보량에 따라 달리한다.
5중 필터는 판단에 사용하되 매 이미지에 다섯 상자를 의무 배치하지 않는다. 중요한 보완점만 하단에 남긴다.

## 색·활자·사진

- 밝은 백색·오프화이트와 짙은 네이비를 기본으로 둔다. 청색은 연결과 공공의 기본 흐름에 사용한다.
- 초록은 지역·학습·지속, 주황은 실험·행동처럼 의미가 있을 때만 보조색으로 쓴다. 경고와 중요한 차이는 절제된 적색으로 표시한다.
- 한 장의 기능색은 기본 2~3개로 제한한다. 더 필요하면 범례를 두고 색만으로 구분하지 않는다.
- 제목→구획 제목→설명→출처의 크기 차이를 명확히 한다. 한국어 중심이며 영어는 보조 표기로 둔다.
- 명조와 고딕은 최대 두 계열을 기본으로 한다. 손글씨는 철학 문장 한 곳 정도에 한정하고 본문에 쓰지 않는다.
- 굵은 Markdown 강조는 쓰지 않는다. 이미지의 시선 위계는 크기·위치·명암을 우선한다.
- 사진·삽화는 주민의 생활과 장소를 설명하는 기능을 맡긴다. 도시 전경은 가장자리나 하단에 낮은 비중으로 두며 글 뒤에 겹쳐 가독성을 떨어뜨리지 않는다.
- 생성된 생활 장면은 ‘개념 이미지’로 표시한다. 실제 인물·현장 사진으로 오인시키지 않는다.
- 협력 미확정 로고 병치는 피한다. 필요하면 ‘협력 제안’ 표시와 함께 명칭을 텍스트로 쓴다. 공식 로고나 얼굴을 임의 재현하지 않는다.

## 밀도와 제작 절차

1. 검증한 텍스트에서 핵심 질문·연결·경험·실험을 추린다.
2. 중심 구조 하나를 골라 큰 구획부터 배치한다.
3. 각 구획은 제목 하나와 짧은 설명·근거 중심으로 채운다. 긴 출처와 세부 과제는 텍스트 별첨으로 옮긴다.
4. 중요한 출처·기준일·‘제안/개념도/미확인’ 표시는 해당 내용 가까이에 남긴다.
5. 이미지 제작 도구를 사용한다. 정확한 표·차트·구조도는 이를 정확하게 그릴 수 있는 도구를 사용한다.
6. 실제 결과를 원본 크기와 축소 화면에서 확인하고 오탈자·잘림·겹침·시선 경쟁을 수정한다. 이미지를 보지 못했으면 시각 검수를 완료했다고 말하지 않는다.

## 발행 전 체크

- 첫눈에 핵심 질문 하나가 보이는가?
- 어떤 기존 자산을 어떻게 연결했는지 보이는가?
- 주민 경험과 작은 실험이 본문에서 사라지지 않았는가?
- 다음 확인과 결과의 학습 환류가 보이는가?
- 상자·사진·색·화살표마다 설명할 역할이 있는가?
- TEXT와 IMAGE의 우선순위·사실·상태가 같은가?
- 예전 이미지의 날짜·목표치·오류를 새 사실처럼 옮기지 않았는가?
- 원본 본문은 읽히며 축소 화면에서 제목·구조·핵심 문장은 남는가?

## 업데이트

새 이미지에 대한 사용자 평가를 받을 때 어느 구성·색·밀도가 좋거나 불편했는지 구체적으로 기록한다.
명시적 수정 요청은 우선 반영한다. 단순한 칭찬을 모든 요소의 영구 승인으로 해석하지 않는다.
반복해서 유효한 문법만 본문 규칙으로 올리고, 예외와 실험적 구성은 참고 사례로 구분한다.
