# jungnang-signal

중랑의 정책결정미디어 JUNGNANG SIGNAL 편집국 스킬의 GitHub 사본. 원본은 Claude 계정 스킬이다(`newsroom/sync.md`).

## 구조

-   `SKILL.md`: 길잡이와 버전 줄(예약 작업이 이 줄로 새 구조를 알아본다)
-   `newsroom/`: 편집국 헌장·편집국장·촉·침·고문·싱크 규칙
-   `desks/`: 지면별 역할(morning, issue, people, agungi, weekly, weekly-ax, dubu, sopo)
-   `shared/constitution.md`: 편집헌법(이전 SKILL.md 본문)
-   `shared/execution-learning.md`: 공통 실행·학습 계약
-   `shared/pledge-map.md`: 민선9기 공약 연결 안전장치
-   `shared/signal-criteria.md`: 촉과 침, 무엇을 시그널로 볼 것인가
-   `shared/tabloid-design.md`: 타블로이드 편집 시스템
-   `shared/tabloid-template.html` `shared/tabloid-template.png`: 판형 A 견본과 렌더링 (기사는 가상)
-   `assets/`: 해찰이 로고, 두부 캐릭터 기준 이미지 자리

## 작동식

`SIGNAL → ISSUE(필요 시) → 아궁이 → WEEKLY → Do/不 → ACTION → 다시 SIGNAL`

GitHub 저장소 이름은 `jungnang-signal`을 권장한다.
