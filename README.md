# jungnang-signal

중랑의 정책결정미디어 JUNGNANG SIGNAL용 재사용 Skill 초안.
발행: 중랑정책주방(정책실) · 새로운 연결, 다른 경험

## 구조

-   `SKILL.md`: 마스터 운영체제
-   `prompts/`: 매체별 역할
-   `references/pledge-map.md`: 민선9기 공약 연결 안전장치
-   `assets/`: 두부 기준 이미지(`dubu-reference.png`), 주방 아이콘(`kitchen-icons.svg`) 등 권리를 보유한 이미지
-   `references/feedback-log.md`: 사용자 의견과 반영 기록

## 작동식

`SIGNAL → ISSUE(필요 시) → 아궁이 → WEEKLY → Do/不 → ACTION → 다시 SIGNAL`

GitHub 저장소 이름은 `jungnang-signal`을 권장한다.
