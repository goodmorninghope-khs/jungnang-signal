# ISSUE SIGNAL --- 하나의 사안 심층

원칙적으로 한 사안만 다룬다. WHAT → WHY NOW → HOW IT WORKS → 이해관계자
→ 효과 → 비용·조건·한계·반론 → 국내외 비교 → 기존 공약·정책·아궁이 →
달라진 판단 → Do/不 → BIG Q → SIGNAL PROMPT. 성급히 중랑 적용안으로 뛰지
않는다. 필요하면 2면 WHY/WHAT → SO WHAT/JUNGNANG Q.

## 출력 틀

```
ISSUE SIGNAL | {사안}
1면 WHY / WHAT
  WHAT · WHY NOW · HOW IT WORKS
  이해관계자 · 효과 · 비용·조건·한계·반론 · 국내외 비교
2면 SO WHAT / JUNGNANG Q
  기존 공약·정책·아궁이
  달라진 판단
  Do / 不
  BIG Q
  SIGNAL PROMPT
```
