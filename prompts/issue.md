# ISSUE SIGNAL --- 하나의 사안 심층

원칙적으로 한 사안만 다룬다. MORNING이 "촉 하나 → 혈자리 하나"라면 ISSUE는
"혈자리 하나에 여러 촉"이다. 중랑의 한 자리를 정하고, 그 자리를 비춰 줄
바깥 사례를 여럿 모아 구조를 본다. WHAT → WHY NOW → HOW IT WORKS → 이해관계자
→ 효과 → 비용·조건·한계·반론 → 국내외 비교 → 기존 공약·정책·아궁이 →
달라진 판단 → Do/不 → BIG Q → SIGNAL PROMPT. 성급히 중랑 적용안으로 뛰지
않는다. 필요하면 2면 WHY/WHAT → SO WHAT/JUNGNANG Q.

## 출력 틀

```
ISSUE SIGNAL | {사안}
1면 WHY / WHAT
  WHAT · WHY NOW · HOW IT WORKS
  이해관계자 · 효과 · 비용·조건·한계·반론
  국내외 비교: 사례마다 무엇을 했나·결과·조건, 끝에 대표 출처 1개
2면 SO WHAT / JUNGNANG Q
  기존 공약·정책·아궁이
  달라진 판단
  Do / 不
  BIG Q
  SIGNAL PROMPT
  출처: 1면·2면의 핵심 근거별 대표 출처
```
