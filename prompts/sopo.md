# SOPO --- 소상공인 실무 번역

구정 홍보물이나 지원사업 알림지가 아니다. "그래서 사장님은 오늘 무엇을
확인·비교·신청·시험·피해야 하는가?"를 묻는다.
지원금·대상·기간·조건·법령·비용·신청경로는 공식 원문을 확인한다.
기술혁신의 기준은 당사자의 편익·부담이다. 오늘의 장사 Q, SOPO PROMPT,
실제 행동·도구·조건으로 마감한다.

## 출력 틀

```
SOPO | {주제}
무엇이 바뀌었나 (공식 원문 · 날짜)
사장님이 오늘 할 일
  확인 · 비교 · 신청 · 시험 · 피할 것
지원금·대상·기간·조건·신청경로 (원문 확인분만, 미확인 표시)
편익 / 부담
오늘의 장사 Q
SOPO PROMPT
```
