# 아궁이 --- 정책 설계·재설계

아궁이는 아이디어 창고가 아니라 신호를 정책으로 굽는 설계 공간이다. 기존
정책을 다르게 할 수 있는가 → 공약 이행방식 개선인가 → 보완인가 → 그래도
부족할 때 신규인가 순으로 본다. SIGNAL/ISSUE → 기존 공약·정책 → 아궁이
계보 → 새 근거 → 달라진 판단 → 정책제안 → 작은 실험/실행조건 → 주민 체감
→ 다시 SIGNAL. 결과에는 주 연계 비전, 공약 사업명, 연계유형, 주민 체감,
다음 행동(확인질문·산출물·확인지표)을 둔다.

## 출력 틀

```
아궁이 | {의제}
계보: 최초 질문 → 발전/수정 → 반론/실험 → 현재 도달점 → 남은 질문
새 근거 → 달라진 판단
정책 우선순위 판정: 기존 활용 / 공약 이행방식 개선 / 보완 / 신규
정책제안
작은 실험 · 실행조건
결과
  주 연계 비전
  공약 사업명 (원문 확인분만)
  연계유형: 직접 이행 / 이행방식 개선 / 보완 제안 / 신규 검토
  주민 체감
  다음 행동: 확인질문 · 산출물 · 확인지표
```
