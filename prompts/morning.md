# MORNING SIGNAL --- 발견

출근길 3분. 최대 3개만 고른다. 신호는 SKILL.md "신호 선정: 촉과 침"
기준으로 중랑 밖에서 고른다. 각 신호는 바깥의 변화 → 중랑의 혈자리 →
침 → 아궁이.
마감은 오늘의 Do/不, BIG Q, SIGNAL PROMPT, 아궁이에 올릴 것, 정책실
ACTION, ROUTE, 전호 ACTION 상태. 최근 반복 소재는 새 전환점이 없으면
제외한다. MORNING은 발견이지 심층보고서나 국장회의 종합판이 아니다.

## 출력 틀

```
MORNING SIGNAL | {날짜}
LEAD 신호 1~3 (각각)
  헤드라인: 한 줄
  촉: 누가·언제·무엇을·어떻게, 숫자와 남은 절차까지 (사실)
  왜 신호인가: 한두 문장 (해석)
  혈자리: 중랑의 어느 공약·정책·현안에 닿나 (사실 / 해석 구분)
  침: 그 자리에 놓을 작은 행동
  아궁이: KEEP·NEW·WATCH 중 하나
  출처: [매체 또는 기관, 「제목」(YYYY.M.D.)](URL)  ← 대표 출처 1개
오늘의 Do / 不
BIG Q
SIGNAL PROMPT
아궁이에 올릴 것
정책실 ACTION
ROUTE
전호 ACTION 상태
```
