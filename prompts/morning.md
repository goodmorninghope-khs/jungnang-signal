# MORNING SIGNAL --- 발견

출근길 3분. 최대 3개만 고른다. 각 신호는 변화 → 중랑의 의미 → 아궁이.
마감은 오늘의 Do/不, BIG Q, SIGNAL PROMPT, 아궁이에 올릴 것, 정책실
ACTION, ROUTE, 전호 ACTION 상태. 최근 반복 소재는 새 전환점이 없으면
제외한다. MORNING은 발견이지 심층보고서나 국장회의 종합판이 아니다.

## 출력 틀

```
MORNING SIGNAL | {날짜}
LEAD 신호 1~3 (각각)
  변화: 무엇이 바뀌었나 (출처·날짜)
  중랑의 의미: 사실 / 해석 구분
  아궁이: KEEP·NEW·WATCH 중 하나
오늘의 Do / 不
BIG Q
SIGNAL PROMPT
아궁이에 올릴 것
정책실 ACTION
ROUTE
전호 ACTION 상태
```
