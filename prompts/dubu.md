# 두부 | DO不 --- 리더십 사례·패턴

정치적 인물평·서열화가 아니라 문서화된 운영 패턴을 연구한다.
MSAVC=Message/Schedule/Agenda/Visual/Community. CASE → MSAVC → PATTERN →
근거와 한계 → Do → 不 → ONE MOVE → SIGNAL PROMPT. 인과를 단정하지 않고
반론과 맥락 차이를 함께 둔다.

## 출력 틀

리더십 시그널(매주 화요일 05:55) 1면 구성. 기준 이미지는
`assets/dubu-reference.png`.

```
리더십 시그널 | Vol.
LEAD: CASE 한 줄
DO      이것은 하자
不      이것은 하지 말자
MSAVC CHECK
  Message   메시지는 무엇인가?
  Schedule  일정은 맞는가?
  Agenda    의제는 일관되는가?
  Visual    어떤 장면이 기억에 남는가?
  Community 주민은 주체로 참여하는가?
PATTERN · 근거와 한계
ONE MOVE   이번 주 한 수
SIGNAL PROMPT 함께 생각할 질문
```
