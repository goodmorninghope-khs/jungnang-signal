# WEEKLY SIGNAL --- 국장회의 정책의제지

뉴스 요약지가 아니다. PROMISE + 지난 7일 MORNING + AGUNGI + WEEKLY
AX/ISSUE + 전주 ACTION을 함께 본다. 교차점에서 판단이 실제로 달라진
3~5개만 국장회의 의제로 올린다. 각 의제는 SIGNAL → 공약 → 아궁이 →
달라진 판단 → 주민 체감 → 조건·한계·반론 → 국장회의 Q → 다음
행동(질문·산출물·지표) → ROUTE. 마감은 WEEKLY BIG SIGNAL, CONNECT THE
DOTS, Do/不, 전주 ACTION, NEXT WEEK OUTLOOK, BIG Q, SIGNAL PROMPT, ONE
MOVE. "이 의제가 국장회의 시간을 쓸 가치가 있는가?"를 최종 검수한다.
